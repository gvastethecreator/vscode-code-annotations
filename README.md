### Getting started

1) Clone [gvastethecreator/vscode-code-annotations](https://github.com/gvastethecreator/vscode-code-annotations), then run `pnpm install`.
2) Press F5 (`Run Extension`).
3) Open a file that contains `TODO` comments.
