## Highlights

- Highlight `TODO`, `FIXME`, `HACK`, `NOTE`, `REVIEW`, and `DEPRECATED` inside comments.
- Browse a native Explorer index grouped by file.
- Filter markers and move to the next or previous result.
- Add literal custom tokens without regular expressions or evaluated code.
- Support desktop, web, virtual, remote, and Restricted Mode.

## Use

Open a file with comment markers, then expand **Code Annotations** in Explorer or run **Code Annotations: Show All**. Select a result to reveal it in the editor.

Workspace scanning starts only when you open the view or run a workspace command. It is bounded, cancellable, and kept in memory. No telemetry, network requests, subprocesses, persistence, webview, or workspace-code execution.

More details: [product contract](docs/PDR.md) · [index design](docs/adr/0001-comment-index.md) · [development](docs/development.md)
