# Security

Code Annotations is local-only. It keeps its bounded index in memory and does not send document contents, paths, annotation messages, configuration, or telemetry off the extension host. It does not execute workspace code or use subprocesses.

Report vulnerabilities through a [private GitHub security advisory](https://github.com/gvastethecreator/vscode-code-annotations/security/advisories/new). Do not open a public issue with exploit details.
